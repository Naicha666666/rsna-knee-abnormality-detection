# D2 跨标签 Stacking（二级模型）验证报告 (Cross-Label Stacking Report)

> **触发背景**：D1 证实了单标签秩传播的有效性；D2 进一步利用全部 4,349 份非金标研究的 OOF 折外预测，通过监督学习自动拟合 12 $\to$ 12 二级模型（Ridge、GBDT），由 58 金标进行纯盲测隔离验收。  
> **核心突破**：
> 1. **单模型自重排（Self-Stacking）**：CoAtNet 单模 AUC 从 **0.8400** $\to$ **0.8476**（**$\Delta = +0.0076$**）；DINO 单模 AUC 从 **0.8256** $\to$ **0.8321**（**$\Delta = +0.0064$**）。
> 2. **双臂联合 Stacking（24 $\to$ 12）**：相比简单 50:50 等权分位秩融合（基线 0.8545），跨标签 GBDT Stacking 直接跃升至 **0.8661**（**$\Delta = \mathbf{+0.0116}$**）！

## 一、 实验协议与零泄漏设计

1. **训练集（Train Set）**：4,349 例非金标研究（严密隔离 58 例金标），以 4,407 多模态精修软标签（`labels_4407_multimodal_refined.parquet`）作为监督目标。
2. **验证/验收集（Val Set）**：58 例金标研究，以放射科金标准二值真实标签为唯一裁决标准（计算 ROC-AUC）。
3. **输入特征（Features）**：
   - 提取自两套独立架构的折外 OOF 预测：CoAtNet-2（`oof.npz`）与 DINOv2/RadImageNet（`v52_e11_oof.csv`），二者中位 Spearman 秩相关仅 0.7346，具备充分的模型多样性。
   - 所有输入特征在各自数据集内严格执行**分位数秩标准化（Percentile Rank Normalization）**，彻底消除训练集与隐式测试集之间的标度偏移（Scale Shift）。

## 三、 Ridge 跨标签权重矩阵学到了什么？（医学共现解析）

在 Ridge 回归拟合的权重矩阵中，算法在 4,349 份病例上**自主发现并量化**了膝关节解剖与病理的深层耦合关系：

1. **Effusion $\to$ Synovitis（滑膜炎借力积液）**：
   $$\text{Pred}(\text{Synovitis}) = 0.254 \cdot \text{Synovitis} + \mathbf{0.249} \cdot \mathbf{Effusion} + \dots$$
   - 算法赋予 Effusion 的权重（0.249）几乎与 Synovitis 自身（0.254）平起平坐！这独立复现了 D1 理论假说（$r=0.77$ 的生理共现），使弱病种 Synovitis 的 AUC 提升 **+0.0173**。
2. **OA 骨关节炎三联征相互强化**：
   - $\text{Pred}(\text{PF OA})$：自身权重 0.485，同时借力 Lateral OA（**+0.146**）与 Medial OA（**+0.098**）及 Synovitis（**+0.097**）。
   - $\text{Pred}(\text{Medial OA})$：自身权重 0.494，受到内侧半月板撕裂（**+0.213**）与 PF OA（**+0.161**）的强烈正向支撑。
3. **半月板与韧带损伤共现**：
   - 交叉韧带损伤与半月板损伤在创伤病例中呈现显著的正相关激励。

## 五、 工程落地：极简部署流水线

D2 Stacker 训练完毕后，模型权重极小（Ridge 权重仅 12×12 = 144 个浮点数；浅层 GBDT 树模型仅数十 KB）。  
在任何推理 Notebook 末尾仅需 3 行代码：

```python
# 推理端秒级接入示例（以 Ridge 12->12 Stacker 为例）
def apply_d2_stacker(pred_df, stacker_weights, labels):
    # 1. 组内秩归一化
    ranks = pred_df[labels].rank(pct=True).to_numpy()
    # 2. 跨标签重排: S = ranks @ W.T + b
    stacked_scores = ranks @ stacker_weights['W'].T + stacker_weights['b']
    pred_df[labels] = stacked_scores
    return pred_df
```
