## 8. 操作备忘（本日实战结论）

- **CLI 直提语法**（CLI 2.2.4）：`kaggle competitions submit -c <comp> -f <输出文件名> -k <owner/slug> -v <版本> -m <描述>`。`-f` 与 `-k` **缺一即 400**；只给 `-f`（文件直传）本竞赛同样 400（Notebook 提交制）。
- **推送身份只认根 `~/.kaggle/access_token`**，`KAGGLE_CONFIG_DIR` 无效；换账户推送 = 备份根 token → 换 → 推 → 恢复。
- **外部数据集挂载**在 `/kaggle/input/datasets/<owner>/<slug>`（伞目录），非 `/kaggle/input/<slug>`。
- **GOLD 机器嫁接必须逐字对齐**（`recipe\cell48_core.txt`）：`read_px` 返回单数组；`order_and_meta` 返回 `([(path,spacing)...], median_ps)`；`eval_windows` 直返张量（不解包）。
- 中文 LOG 条目必须经 python `io.open(..., 'a', encoding='utf-8-sig')` 追加（PowerShell here-string 会 GBK 损坏）。
