# R1 报告召回表：报告到底写出了多少专家标签

> 2026-10-01，LOG #479。对应研究问题 RQ1（报告作为弱监督的天花板）。脚本 `scratchpad/report_recall.py`，数值表 `results/report_recall_v1.csv`，逐病例表 `results/report_recall_cases_v1.csv`。

## 一句话结论

用报告做监督，失效有两种方式：**漏报**（专家标了阳性，报告没写）和**阈值不一致**（报告写了，专家不算阳性）。

- **漏报**集中在 Synovitis（44% 的专家阳性没被报告写出）、Fracture（28%）和三个 OA / 外侧半月板标签（17–19%）。
- **阈值不一致**集中在 Effusion：70% 的专家阴性，报告里写了积液。
- 在 12 个标签上，**报告对专家阳性的召回率**与模型的金标 AUC 秩相关 **0.70–0.81**。模型在哪个标签上弱，很大程度上可以从"报告在这个标签上漏了多少"预测出来。

## 方法

**样本**：58 例金标。按专家标签分成阳性 P 和阴性 N，对每份报告判定状态。

**正则抽取器的四种状态**（`report_extractor.extract_raw` 的输出，未改动生产代码）：
- **明确阳性**：至少有一处阳性断言。
- **可疑**：只有 possible / suspected 一类的表述（`_grade` 的可疑分支，置信度恰为 0.55）。
- **明确阴性**：只有否定或"正常"的表述。
- **未提及**：以上都没有。Synovitis 会走一个兜底分支，分数可能 ≥ 0.5，但置信度是 0.18，仍算作未提及。

**LLM 交叉核对**：4 个 LLM（Kimi、Qwen、Grok、Gemma4）的平均概率 ≥ 0.5 记为"报告说阳性"。LLM 读的是整份报告，能识别正则漏掉的措辞。正则抽取器在金标上的 AUC 只有 0.865，所以**正文结论以 LLM 列为准**。

## 发现

### 1. 漏报：Synovitis 的监督天花板

- **监督信号本身就缺一半**：27 例专家阳性中，报告明确写出的只有 48%（正则），LLM 也只认出 56%，其余 52% 根本没提。
- **未提及的报告里，阳性和阴性差不多一样多**：全部 58 份报告中有 71% 对滑膜炎只字未提，专家阴性里未提及的占 87%。训练时，这些未提及的病例都只能拿到一个由积液程度推出的弱先验。
- **能解释 #473 和 #477 看到的现象**：Synovitis 的报告目标只有 0.763，模型反而超过了它（0.832），在公榜上是 0.908。模型多出来的部分只可能来自图像，主要是积液：27 个 Synovitis 阳性里有 22 个同时是 Effusion 阳性。
- **对计划里"未提及 → 忽略损失"的含义**：对 Synovitis 套用这条规则，会把 71% 的病例从损失里拿掉，监督只剩明确提及的约 30%。阳性那一半的错误信号确实没了，但阴性的信号也几乎全丢了。**这个方案对 Synovitis 不划算**。对漏报主要落在"未提及"、而阴性大多被明确否定的标签，它才可能有用：比如 Lateral OA，P 中未提及占 36%，N 中未提及却高达 79%，同样不理想。所以这条规则在本数据上**没有一个明显适用的标签**。

### 2. 阈值不一致：Effusion 的问题出在特异性

- **报告对专家阳性一个不漏**（LLM 召回 1.00），**但 70% 的专家阴性在报告里也写了积液**。专家没有把报告里提到的积液都算作阳性。
- **严重度有区分能力**：只看报告写了积液的 49 例，正则的严重度分数仍能把专家阳性和阴性分开，AUC 0.74。"少量 / 生理性"的积液，专家多半不算。
- **验证并排除了一个替代解释**：读原始报告时，我猜过专家会把"积液 + 滑膜增厚"整体标为 Synovitis 而不是 Effusion（类似 MOAKS 的 effusion-synovitis 合并条目）。交叉表不支持：报告写了积液但专家标 Effusion=0 的 16 例中，只有 4 例被标为 Synovitis。在 27 个 Synovitis 阳性里，22 个同时是 Effusion 阳性。专家并没有拿 Synovitis 替代 Effusion。
- **同类问题较轻的标签**：Contusion（N 中报告说阳性 33–41%，严重度 AUC 0.76）和 Medial Meniscus（正则 34%、LLM 19%，严重度 AUC 0.74）。
- **图像在这里补得最多**：模型 AUC 超过报告目标最多的三个标签正是 Effusion（+0.114）、Fracture（+0.096）和 Contusion（+0.082）。这三类在影像上直接可见，图像能补上报告在阈值和漏报上的缺陷。

### 3. 报告召回率能预测模型在哪里弱

在 12 个标签上做秩相关：

| | 与基底代理 AUC | 与 CoAt 家族 AUC | 与派生尺子（DINO 模仿报告） |
|---|---:|---:|---:|
| LLM 对专家阳性的召回 | **0.70** | **0.81** | −0.16 |
| 报告目标 AUC | 0.56 | 0.60 | −0.15 |

- **召回率比报告目标 AUC 更能预测模型的弱项**：报告目标 AUC 把漏报和阈值两种问题混在一起，而阈值问题（Effusion）能被图像补回来，漏报问题补不回来。
- **跟"模仿报告"的能力无关**（−0.16）：模型在漏报多的标签上弱，不是因为没学会模仿报告，而是因为报告本身就缺这部分信息。
- **公榜按标签探测确认的 4 个弱标签**（Synovitis、PF OA、Lateral OA、Lateral Meniscus，#477），正好是 LLM 召回最低的 5 个标签里的 4 个。剩下那个是 Fracture，它的召回虽低（0.72），但骨折在图像上很显眼，模型能自己补回来。

### 4. 反例：PF OA 的监督不缺，模型却跟不上

PF OA 的报告目标（0.912）**高于**模型（0.865），是唯一一个模型明显落后于自身监督的弱标签。这与 #473 的初判"表示 / 覆盖瓶颈"一致：报告信息够了，模型没学出来。

## 局限

1. **样本量**：每个标签只有 9–35 个阳性，表中比例的 95% CI 宽度约 ±0.10–0.30。12 个点的秩相关也只能看方向。
2. **"召回"由 LLM 判定**，本身有误差。不过 4 个 LLM 取平均，而且正则与 LLM 的趋势一致。
3. **样本有重叠**：模型 AUC 和召回率都在同一批 58 例上测量，样本不独立。另外公开 CoAt 读者按金标选轮，CoAt 那一列的 AUC 偏乐观。
4. **看不到阈值本身**：不知道专家的标注规程（"多少积液算阳性"），只能从数据反推。

## 对后续工作的含义

- **RQ1 论点**：报告作为弱监督，天花板由**漏报率**决定，而不是由报告目标的整体 AUC 决定。漏报补不回来；阈值不一致可以靠图像补回来。这为"金标质量提升但 LB 不动"（C6s、C6k）给出了一个可检验的解释：那两次改动提升的主要是 LLM 对报告的**理解**，没有、也不可能改变报告本身的**漏报**。
- **计划里的"未提及 → 忽略损失"**：在本数据上没有明显适用的标签，**不建议做**。
- **比赛侧**：漏报型标签只能靠图像提升，而图像侧的自研尝试都已收口。PF OA 是唯一一个"监督够、模型差"的标签，可以作为后续表示 / 覆盖实验的对象（RQ2）。
